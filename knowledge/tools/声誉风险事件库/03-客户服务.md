## 3.1 业务办理及服务态度

**核心隐患要点**

1. 员工出现服务瑕疵：服务态度问题、沟通不当、业务处理疏失。
2. 外包人员在对客服务中出现数据泄露、违规使用客户信息。

**舆情场景描述**

1. 业务办理中出现缺乏耐心、未按流程操作、业务回答错误、违规营销（"放心投""闭眼入"等），引发舆情。
2. 外包人员合规意识薄弱，在对客过程中可能将企微的客户画像或标签内容告知客户，引发客户质疑。

**前置预防举措**

1. 服务话术库：制定客服标准服务话术。
2. 纳入考核：将服务态度、业务疏失、违规营销等与绩效考核挂钩，强化员工合规意识。
3. 稽核与培训：通过智能质检系统开展服务、营销敏感词自查与抽查，对高频问题人员开展专项约谈再培训；对外包人员开展合规行为宣贯培训，明确严禁将内部系统数据、客户画像标签等信息向客户透露或对外泄露，要求人员按《企微服销一体化手册》规范执行。

**各处室补充**

### 客户服务中心（重点补充）

**核心隐患要点（客服中心视角）**

1. 客服人员服务语气不耐烦、机械应答、推诿搪塞、缺乏同理心，对待客户咨询投诉消极应对。
2. 客服情绪失控、顶撞客户、言语过激、嘲讽客户，引发口角对立。
3. 业务知识不熟练、规则解读错误、随意承诺业务办理结果、误导客户办理产品。
4. 受理投诉及业务诉求后拖延处理、推诿、超时无反馈、闭环处置不到位。
5. 违规查询客户业务信息、私自透露账户信息、通话及泄露客户隐私、违规代办业务。
6. 客服登记信息错误、业务办理差错、限额/挂失/解绑操作失误。

**舆情场景描述（客服中心视角）**

1. 客户咨询银行卡扣费、贷款还款、理财产品赎回等问题，客服语速过快、打断客户说话，重复套话不解答实际问题；客户遭遇资金损失或诈骗求助时，客服冷漠敷衍、未主动安抚，引发客户录制通话录音，发抖音、小红书、微博吐槽，形成舆情。
2. 客户对业务规则、处理结果不认可提出质疑，客服强行辩解、言语抬杠，甚至使用嘲讽、指责性语言；客户将通话录音、在线聊天截图转发社交平台、论坛，引发网友围观，发酵负面舆论。
3. 客服对信用卡年费、贷款利率、理财产品规则等业务解答错误，误导客户办理分期、理财、信用卡业务，后续产生费用纠纷、亏损；客户维权无果后发帖曝光，引发"银行客服虚假宣传、误导消费"舆情，甚至诱发投诉监管、媒体介入。
4. 客户投诉盗刷、扣费异常、业务纠纷，客服受理后迟迟无回访、无处理结果；多次致电被反复推诿，问题长期悬而未决，客户向黑猫投诉、12378、社交媒体发帖维权，扩散"银行投诉无门、办事效率低下"负面形象。
5. 客服违规向第三方透露客户银行卡余额、账单、住址、手机号等隐私信息；或私下违规协助非本人办理解绑、限额调整等业务，引发客户资金被盗、隐私泄露，事件曝光后引发公众对银行信息安全的信任危机。
6. 客服登记客户手机号、证件信息、业务诉求错误，导致业务办理失败、账户功能异常，客户曝光录音及业务凭证，引发舆情质疑银行业务操作不严谨、不负责任。

**前置预防举措（客服中心视角）**

1. 制定标准服务话术、服务忌语清单，明确禁止敷衍、打断、冷漠式应答；开展同理心服务、情绪沟通专项培训，重点针对投诉、资金受损类客户沟通场景演练；质检加大抽检力度，对语气生硬、敷衍应答纳入扣分考核。
2. 建立客服情绪疏导机制，加大现场巡查力度，发现情况时班组长或运营主管及时介入，避免情绪失控；明确冲突处置规范，要求客户异议时不得正面争执，实行"先安抚、再解释、后升级"流程；对出现言语争执、顶撞客户引发负面舆情的，实行一票否决考核，同时开展案例警示教育。
3. 根据业务部门报备及时更新业务知识库；遇相关问题时主动寻求业务主管部门帮助；要求客服通过相关业务考试，不合格不得提供相关服务；严禁客服私自承诺审批结果、费息减免等不确定事项，统一规范承诺口径；新业务、新产品上线前开展全员专项培训，针对重点业务在存续期间重复培训，巩固业务知识基础；对业务解答错误、误导类，纳入个人质检、培训清单。
4. 明确各类业务、投诉办理时限及回访节点，系统自动超时预警；建立首问负责制，禁止简单推诿，需协助对接的明确专人跟进反馈，遇到无法推动时主动升级处理层级；投诉工单全流程留痕，超时未办结时及时跟进督办；定期梳理高频积压诉求，优化办理环节，减少客户反复致电。
5. 严格执行身份核验流程，非本人业务坚决不予查询、不予办理，系统设置权限管控；开展信息安全、保密合规专项培训，明确隐私泄露处罚红线；后台操作全程日志留痕，定期抽查异常查询、违规操作记录；严禁客服私加客户微信、私下沟通业务，杜绝线下信息泄露渠道。
6. 业务录入后实行二次核对确认制，与客户复述关键信息确认无误再提交；建立差错快速更正通道，明确差错整改时限；定期统计操作差错率，对高频出错人员开展专项复训、帮扶。

### 远程经营中心（补充·3.1）

**核心隐患要点**

1. 与客户沟通时出现服务瑕疵、沟通方式不当、业务处理疏失及违规营销，引发客户投诉。
2. 外包合规意识薄弱，可能将生产中的信息直接告知客户，引发合规风险。

**舆情场景描述**

1. 业务办理中出现缺乏耐心、未按流程操作、业务回答错误（活动告知不准确等）、违规营销（"放心投""闭眼入"等），通过95561进线投诉或12378等平台投诉员工服务态度问题。
2. 外包人员合规意识薄弱，在对客过程中可能将企微的客户画像或标签内容告知客户，引发合规风险。

**前置预防举措**

1. 将服务态度、业务疏失、违规营销等与绩效考核挂钩；定期通过智能质检系统开展服务、营销敏感词自查与抽查，对高频问题人员开展专项约谈再培训。
2. 对外包人员开展合规行为宣贯培训，明确严禁将内部系统数据、客户画像标签等信息向客户透露或对外泄露，要求人员按《企微服销一体化手册》规范执行。

## 3.2 对客公告与批量资产处置

> 来源：2026-07-31「兴业银行关于保管箱逾期租户限期办理续租及退租手续的公告」声誉风险评估（`work/声誉风险评估/20260731-保管箱逾期租户限期办理续租及退租手续的公告/`），安之 2026-07-31 确认入库。
> **适用范围**：以公告形式对客户单方告知并启动批量处置动作的事项——逾期资产清理、长期不动户/睡眠账户处理、欠费追缴、合同到期强制终止、寄存物品清理等。与 3.1 的区别：3.1 是**服务过程中**的人员瑕疵，本节是**制度性动作**在设计与告知环节的缺陷，一旦执行即不可逆。

**核心隐患要点**

1. **"清理逾期客户"被表述为"清退该业务"的口径外溢风险**：评估表、内部论证材料或对外口径中，把"清理一批逾期客户"论证成"清退低效高风险业务""压降该业务规模"。两者性质完全不同——前者针对个别违约客户，后者指向业务本身的存废。该表述一旦被引用为对外口径或流出，**正常存续的守约客户会理解为本行将退出该业务**，转而担心自身资产/物品的处置去向，把一次针对少数人的催收行动放大成全体客户的信任事件。**判别方法**：核对内部论证的"事由"与公告的"实际动作"是否指向同一对象；论证里出现"清退""退出""压降"而公告只写"清理逾期"的，一律要求改写。**前置预防**：内部论证材料同样按对外口径标准审核，不能因为"这是内部材料"就放宽——评估表会随审批链流转，并可能成为答复监管、答复媒体的底稿。

2. **对外承诺的操作动作超出合同约定，与保密义务冲突**：处置类事项为安抚客户，常在备答口径中主动加码承诺操作细节（如"对物品逐一登记、**拍照**、封存""全程录像留档"）。若合同约定的动作只是"登记保管"，且合同另有"对存放物品不得登记、保证保密"一类义务，主动承诺拍照/录像反而**给客户递上了主张"未经授权拍摄私密财物"的把柄**——本意是自证规范，结果自造了一个新的争议点。**判别方法**：对外承诺的每一个动作，逐个回合同找依据；合同没写的动作不主动说。**前置预防**：处置类口径统一表述为"在公证机关（或有权机关）监督下清点、登记、封存，全程留痕"，不列举具体取证手段。

3. **批量催收/资产处置名单未核查客户存活状态**（本节最高爆点）：批量清理的对象画像通常是"逾期时间长 + 多次催缴无回应"，而这个画像与"客户已身故"高度重合——长期失联的一大成因就是本人已不在。若名单未做存活状态核查即执行处置，**继承人事后发现先人的保管箱被凿开、遗物被变卖，或先人账户资产被划扣**，这类场景在舆论场上几乎没有辩解空间：情感冲击强、画面感强、且本行"不知情"的抗辩会被反问"为什么不查"。多数合同对身故情形另有专门约定（如接到死亡通知应立即封箱、继承人凭死亡证明与继承公证书办理），执行流程若不衔接这一条，等于合同写了而流程不认。**判别方法**：凡涉及批量处置客户财产/物品的事项，问一句"名单里的人还都在吗，怎么确认的"。**前置预防**：①在名单确认环节增加存活状态核查（联系人回访、身份信息状态核验、系统身故标识比对等）；②发现身故线索的**单独移交继承流程处理，不纳入本次批量清理**；③把该核查写成执行前置条件，而非事后补救。**关联案例**：`[行业案例:20260731-批量资产处置名单未核查身故客户.md]`

4. **对客公告类事项须通读合同原文比对，不得只依赖消保审查意见**（方法论要点，评审动作）：公告的合法性锚点是合同，而消保审查的关注面是消费者权益条款是否公平、告知是否充分，**不必然覆盖"公告写的与合同约定是否一致"**。实测：2026-07-31 保管箱公告评估中发现的三处公告与合同冲突，只有一处（引用了合同中不存在的条款名）被消保审查提出，另两处是通读合同原文才发现的——①**处置时序被压缩**：合同约定两个连续的六个月（届满超六个月可公证凿箱、凿箱之日起再超六个月方可处置），公告只给"60个自然日"一个期限且三项措施均以"合同约定的相关办理期限"起算，处置阶段的第二个六个月在公告中完全消失，按字面执行即构成违约处分客户财物；②**押金口径与合同方向相反**：合同为"扣收其全部押金"，公告写成"抵扣欠费+不足部分追偿"，客户按公告主张余额退还、系统按合同扣收全部，必然形成收费争议。**前置预防**：评估"依据合同对客户采取措施"类事项时，把合同原文列为**必读材料**（处室标注"背景参考无需评估"的也要读），逐条比对公告中每一项措施的**触发条件、起算时点、时长、金额处理方式**四要素是否与合同一致；不一致的一律退回明确，不替处室猜哪个对。

5. **以删除对客披露回应"公告与合同冲突"整改意见的反向整改风险**：对客公告经评审指出"处置时序、费用口径与合同约定不一致"后，处室的整改动作可能不是**订正口径**，而是**删除该节披露**——把写错的部分整段拿掉，冲突表面消失，评审意见形式上"已处理"。但合同约定的处置动作并未取消，客户实际面临的后果不变，改变的只是客户在办理期内能否知晓后果。三重后果：①**知情权实质倒退**，客户无从判断"不处理会怎样"，也就无从据此决定是否办理，公告的督促功能同步失效；②**本行举证地位反而更差**，事后客户主张"公告里根本没说要开箱/扣款"时，本行既无公告依据可援引，也无法证明已充分告知；③**偏差空间扩大**，原先至少写明的时序节点全部消失，执行人员与客户对"多久之后会发生什么"各自理解。**判别方法**：对比整改前后两版，逐节点数——**披露内容变少的，一律追问"对应的实际动作取消了吗"**；动作没取消而披露没了，即为反向整改。**与本节 #1 的区别**：#1 是内部论证口径外溢到对外材料（说多了），本条是对外披露被删（说少了），两者都属"公告与实际动作不对应"，方向相反。**监管依据**：`[法规:消保办法#第二十三条]`（不得欺诈、隐瞒、误导，保障知情权）；《中华人民共和国消费者权益保护法》第八条（知悉真实情况的权利）、第十条（公平交易权）。**行业参照**：同业公开的保管箱租赁协议同样采用"公证破箱→再满六个月方可处分"的两阶段结构并对外披露，如实披露不构成额外风险，删除披露反而是异常做法。**关联案例**：2026-08-05 保管箱逾期租户限期办理续租及退租手续的公告修改版评审（`work/活动评审/20260805-官网发布保管箱逾期租户限期办理续租及退租手续的公告/`）——2026-07-31 首评指出公告处置时序被压缩为 60 日、押金口径与合同相反、援引合同不存在的条款名，修改版直接删除整节「三、处理措施」，五处冲突中两处随删节消失、三处未整改。**前置预防**：①评审意见中凡指出"口径与合同不一致"的，须同时写明期望的整改方向（改为与合同一致的正确表述），不能只写"存在冲突"，避免处室以删除结案；②复审时以**上一版材料**为基准逐节比对，不只看当前版本是否还有错；③对客公告的披露完整性单列核查项——合同约定的每一项对客户不利的措施，公告中是否都有对应告知。

**前置预防举措（本节通用）**

1. **告知有效性不能只靠公告**：单方处置客户财产的事项，仅发官网/网点公告的举证强度最弱。须在处置动作前对每一户完成不少于两种方式的定向通知（短信、电话、信函、客户经理），并全程留痕。**注意一个常见的反向论证**：处室常以"该业务客户范围窄、为避免打扰"为由拒绝增加渠道——客户范围窄恰恰使逐户定向通知成本可控、效果最好，该理由与结论方向相反，应予纠正。
2. **费用披露到项**：涉及欠费清收的，须列明计费标准（含违约金）、各项费用的收取依据、清偿顺序、押金/保证金抵扣结果与余额退还方式，不得只写"及由此产生的相关费用"。
3. **应急预案须单列不可逆中间态的回退办法**：处置类事项一旦中途暂停，会遗留"已扣款/已开箱/已封存"等中间状态。预案不能只写"暂停活动"，须明确这批客户如何回退、由谁负责、多久内告知。
4. **客服话术禁止责任外推开场**：客户称"从未收到通知"时，在本行催缴留痕尚未调取核实前，先说"可能是您的联系方式变更未及时更新"属于责任外推，是最易被录音传播的话术形态（命中 3.1 客服中心视角第 2 项）。正确顺序是：先致歉 → 承诺立即调取催缴记录并向客户出示 → 明确办理期内办理不受影响。合同的送达条款可在必要时作为说明依据，但不作为对话开场。
