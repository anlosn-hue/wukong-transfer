# 声誉风险事件库 · 03 客户服务

> 来源：《负面舆情风险隐患排查要点表》第3类
> 子类：3.1 业务办理及服务态度

## 3.1 业务办理及服务态度

**核心隐患要点**

1. 员工出现服务瑕疵：服务态度问题、沟通不当、业务处理疏失。
2. 外包人员在对客服务中出现数据泄露、违规使用客户信息。

**舆情场景描述**

1. 业务办理中出现缺乏耐心、未按流程操作、业务回答错误、违规营销（"放心投""闭眼入"等），引发舆情。
2. 外包人员合规意识薄弱，在对客过程中可能将企微的客户画像或标签内容告知客户，引发客户质疑。

**前置预防举措**

1. 服务话术库：制定客服标准服务话术。
2. 纳入考核：将服务态度、业务疏失、违规营销等与绩效考核挂钩，强化员工合规意识。
3. 稽核与培训：通过智能质检系统开展服务、营销敏感词自查与抽查，对高频问题人员开展专项约谈再培训；对外包人员开展合规行为宣贯培训，明确严禁将内部系统数据、客户画像标签等信息向客户透露或对外泄露，要求人员按《企微服销一体化手册》规范执行。

**各处室补充**

### 客户服务中心（重点补充）

**核心隐患要点（客服中心视角）**

1. 客服人员服务语气不耐烦、机械应答、推诿搪塞、缺乏同理心，对待客户咨询投诉消极应对。
2. 客服情绪失控、顶撞客户、言语过激、嘲讽客户，引发口角对立。
3. 业务知识不熟练、规则解读错误、随意承诺业务办理结果、误导客户办理产品。
4. 受理投诉及业务诉求后拖延处理、推诿、超时无反馈、闭环处置不到位。
5. 违规查询客户业务信息、私自透露账户信息、通话及泄露客户隐私、违规代办业务。
6. 客服登记信息错误、业务办理差错、限额/挂失/解绑操作失误。

**舆情场景描述（客服中心视角）**

1. 客户咨询银行卡扣费、贷款还款、理财产品赎回等问题，客服语速过快、打断客户说话，重复套话不解答实际问题；客户遭遇资金损失或诈骗求助时，客服冷漠敷衍、未主动安抚，引发客户录制通话录音，发抖音、小红书、微博吐槽，形成舆情。
2. 客户对业务规则、处理结果不认可提出质疑，客服强行辩解、言语抬杠，甚至使用嘲讽、指责性语言；客户将通话录音、在线聊天截图转发社交平台、论坛，引发网友围观，发酵负面舆论。
3. 客服对信用卡年费、贷款利率、理财产品规则等业务解答错误，误导客户办理分期、理财、信用卡业务，后续产生费用纠纷、亏损；客户维权无果后发帖曝光，引发"银行客服虚假宣传、误导消费"舆情，甚至诱发投诉监管、媒体介入。
4. 客户投诉盗刷、扣费异常、业务纠纷，客服受理后迟迟无回访、无处理结果；多次致电被反复推诿，问题长期悬而未决，客户向黑猫投诉、12378、社交媒体发帖维权，扩散"银行投诉无门、办事效率低下"负面形象。
5. 客服违规向第三方透露客户银行卡余额、账单、住址、手机号等隐私信息；或私下违规协助非本人办理解绑、限额调整等业务，引发客户资金被盗、隐私泄露，事件曝光后引发公众对银行信息安全的信任危机。
6. 客服登记客户手机号、证件信息、业务诉求错误，导致业务办理失败、账户功能异常，客户曝光录音及业务凭证，引发舆情质疑银行业务操作不严谨、不负责任。

**前置预防举措（客服中心视角）**

1. 制定标准服务话术、服务忌语清单，明确禁止敷衍、打断、冷漠式应答；开展同理心服务、情绪沟通专项培训，重点针对投诉、资金受损类客户沟通场景演练；质检加大抽检力度，对语气生硬、敷衍应答纳入扣分考核。
2. 建立客服情绪疏导机制，加大现场巡查力度，发现情况时班组长或运营主管及时介入，避免情绪失控；明确冲突处置规范，要求客户异议时不得正面争执，实行"先安抚、再解释、后升级"流程；对出现言语争执、顶撞客户引发负面舆情的，实行一票否决考核，同时开展案例警示教育。
3. 根据业务部门报备及时更新业务知识库；遇相关问题时主动寻求业务主管部门帮助；要求客服通过相关业务考试，不合格不得提供相关服务；严禁客服私自承诺审批结果、费息减免等不确定事项，统一规范承诺口径；新业务、新产品上线前开展全员专项培训，针对重点业务在存续期间重复培训，巩固业务知识基础；对业务解答错误、误导类，纳入个人质检、培训清单。
4. 明确各类业务、投诉办理时限及回访节点，系统自动超时预警；建立首问负责制，禁止简单推诿，需协助对接的明确专人跟进反馈，遇到无法推动时主动升级处理层级；投诉工单全流程留痕，超时未办结时及时跟进督办；定期梳理高频积压诉求，优化办理环节，减少客户反复致电。
5. 严格执行身份核验流程，非本人业务坚决不予查询、不予办理，系统设置权限管控；开展信息安全、保密合规专项培训，明确隐私泄露处罚红线；后台操作全程日志留痕，定期抽查异常查询、违规操作记录；严禁客服私加客户微信、私下沟通业务，杜绝线下信息泄露渠道。
6. 业务录入后实行二次核对确认制，与客户复述关键信息确认无误再提交；建立差错快速更正通道，明确差错整改时限；定期统计操作差错率，对高频出错人员开展专项复训、帮扶。

### 远程经营中心（补充）

**核心隐患要点**

1. 与客户沟通时出现服务瑕疵、沟通方式不当、业务处理疏失及违规营销，引发客户投诉。
2. 外包合规意识薄弱，可能将生产中的信息直接告知客户，引发合规风险。

**舆情场景描述**

1. 业务办理中出现缺乏耐心、未按流程操作、业务回答错误（活动告知不准确等）、违规营销（"放心投""闭眼入"等），通过95561进线投诉或12378等平台投诉员工服务态度问题。
2. 外包人员合规意识薄弱，在对客过程中可能将企微的客户画像或标签内容告知客户，引发合规风险。

**前置预防举措**

1. 将服务态度、业务疏失、违规营销等与绩效考核挂钩；定期通过智能质检系统开展服务、营销敏感词自查与抽查，对高频问题人员开展专项约谈再培训。
2. 对外包人员开展合规行为宣贯培训，明确严禁将内部系统数据、客户画像标签等信息向客户透露或对外泄露，要求人员按《企微服销一体化手册》规范执行。
