## 2. 声誉风险事前评估表 · 填写质量标准

声誉风险事前评估表分四大模块，各模块有填写质量要求：

### 一、评估事项
**要求：** 概括评估事由、进展、可能引发的声誉风险点。

**合格表述：** 明确说明"本次活动通过手机银行/企微推送优惠券，存在客户因优惠条件理解偏差投诉的风险"
**不合格表述：** 仅写"因开展营销活动，存在一定声誉风险"（过于笼统）

### 二、声誉风险评估
**要求：** 从以下角度进行分析，并给出分级结论：
- **重视可行性与民众认可度**：是否符合政策导向、民心所向
- **舆论关注度**：是否易引发公众大面积关注，能否引发负面争议
- **舆论关联关系**：是否易引发社会联想，造成较大社会面影响
- **总体影响**：从发生概率角度判断，预测整体声誉影响量级

**定级依据必须能与分级模型对应**（见 `05-评估准确性.md`）。

**常见敷衍表述（直接标注不合格）：**
- "可行，关注度低"
- "无风险"
- "符合要求"（无具体依据）
- 千篇一律的模板化表述（多个申请内容完全相同）

### 三、处置预案
**要求：** 提供针对可能出现的声誉风险点的处置方案，包含：
- 触发条件（何时启动）
- 具体处置步骤
- 回撤/停止机制（如适用）

**不合格表述：** "如出现问题及时处理"、"按相关规定执行"（无具体操作步骤）

### 四、媒体备答口径
**要求：** 对可能产生舆情及媒体来询的情况进行预设，提供标准化口径。

**检查点：** 是否有至少1条具体的问答口径（Q&A形式或正式声明格式）。

## 3. 广告宣传规范审核表 · 关键检查项（自制素材适用）

仅在处室提交了自制宣传素材时核查此部分。

### 价值观类（一票否决）
- [ ] 不含违反社会主义核心价值观的内容
- [ ] 不损害国家尊严、不涉及国旗/国徽/国歌的不当使用
- [ ] 不含封建迷信、色情、赌博、暴力、恐怖内容
- [ ] 不使用外国国旗/国徽/国歌

### 法律规范类（一票否决）
- [ ] 不违反金融广告相关法规（保险、存款、贷款等各有专项规定）
- [ ] 不含"国家级"、"最高级"、"最佳"等极限用词
- [ ] 不含虚假宣传或无法实现的产品承诺
- [ ] 不含医疗/治疗效果声明
- [ ] 不涉及不正当竞争（对比同业、贬低竞争对手）

### 敏感信息类
- [ ] 不含未经授权的人物肖像
- [ ] 不含个人隐私或个人信息
- [ ] 场景/道具无政治敏感元素
- [ ] 配乐无版权问题
- [ ] 图片来源合规，无侵权

### 联合营销类（涉及联名/跨界时）
- [ ] 联名品牌近期无重大负面新闻
- [ ] 联名品牌无监管层面的违规记录

### VI规范
- [ ] 符合兴业银行VI手册规范（Logo/字体/色彩/排版）

## 4. 消保审查表 · 完成性核验

消保审查为声誉风险评估的**前置条件**，在材料规范性中核验：

**核验内容：**
- 消保审查表是否已填写（有签字/日期）
- 消保审核员是否已签署
- 消保完成日期是否早于声誉风险评估提交日期

**注意：** 消保审查表的具体内容（八大权利/营销规范）在④事项合理性中评估。

## 5. 跨材料一致性核验（钩稽比对）

> 检查的不是单份材料是否合格，而是**同一字段在多份材料间是否对得上**。
> 本节与②的"审批单比对协议"同源：②比的是流程/身份，本节比的是内容/文本。

### 核验字段清单

逐字段在 方案 / 物料 / 话术 / 评估表 之间交叉核对，任一项串不上即为材料硬伤：

| 字段 | 典型不一致 |
|------|-----------|
| 参与对象 / 客群范围 | 方案"全行客户" vs 物料"全行零售客户" vs 话术"白名单客户" |
| 活动时间窗口 | 方案 6 月 vs 海报 7 月；起止日期不一致 |
| 优惠力度 / 门槛 | 方案"满 300 减 50" vs 物料"满 200 减 50" |
| 权益数量 / 库存 | 物料"限量 1000 份" vs 方案预估 5000 份 |
| 利率 / 费率 / 收益数字 | 各材料数字不一致 |
| 活动名称 | 方案与物料名称不符 |
| 适用产品 / 渠道范围 | 适用产品或投放渠道口径不一致 |
| **对外联系方式（客服热线 / 链接 / 二维码）** | 短信热线写 96651、物料写 95561；短链/二维码指向与文案不符或失效 |

> **对外联系方式专项（真实性核验，非仅一致性）：** 客服热线、通信码号、短链、二维码等"对外可触达入口"是高频整批复制字段，**易整批写错且看起来内部一致**。核验时不能只做材料间互比，须与**权威值**比对（官方客服热线、正确落地页）。错号/错链直接误导客户、触 `[法规:网络营销办法#第九条]`（客服热线须真实可核实）。参见案例 `cases/20260616-触达短信客服热线错号.md`。

> 不止跨材料，**单份材料内部**也要查自洽（如海报标题写"全行"、正文写"零售"）。

### 核验原则

1. **不默认任何一方为准。** 发现不一致一律退回处室明确口径，不替处室猜哪个对——因为两个方向的错风险不同：
   - 物料口径比方案**宽**（方案零售、物料写全行）→ 不符合条件的客户看到优惠却无法兑现 → 虚假宣传 / 投诉风险（关联④知情权）
   - 物料口径比方案**窄**（方案全行、物料写零售）→ 应享客户被排除 → 公平交易权投诉 + 业务目标落空（关联④公平交易权）
2. **只提交一类材料时**，跨材料比对无法执行，退一步与评估表"评估事项"的自述口径对齐——这是兜底锚点。
3. 发现不一致时，**在③标注为材料硬伤、退回**，同时在④事项合理性标注其下游权利风险。


## 关键监管引用：《金融产品网络营销管理办法》

来源：中国人民银行等八部委，2026年4月21日发布，**2026年9月30日起施行**。
完整条文：`knowledge/tools/管理机制/国家法律法规/金融产品网络营销管理办法.md`

**第十条核心禁止行为（影响宣传物料/话术合规检查）：**
- 虚假或引人误解的内容
- 引用不真实/未经核实的数据
- 明示或暗示保本、承诺收益、预测未来业绩、展示模拟业绩
- 夸大保险责任或与存款/理财产品简单类比
- 误导消费者认为监管审批=保证
- 诱导分期消费（片面宣传首期费用优惠）
- 使用"低风险""低门槛""秒到账""高收益""低利率""无成本"等诱导性用语

> 本次仅收录第十条。全文法规对照见后续 V1.2 升级计划。
