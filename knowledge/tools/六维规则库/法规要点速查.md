## A. 网络营销办法（数字营销 / 网络推介 / 第三方平台合作 场景）

| 条款 | 要点 | 触发场景 |
|------|------|---------|
| 网络营销办法#第七条 | 营销内容须总部统筹审核备案、合规审查，审核材料存档备查 | 自制物料/话术 |
| 网络营销办法#第八条 | 产品名/提供者/类别/利率费率/风险提示等关键信息须与合同一致、清晰醒目、无遗漏误导 | 含产品信息的物料 |
| 网络营销办法#第九条 | **客服热线、通信码号资源须真实披露供消费者核实** | 物料/话术含热线、码号、链接 |
| 网络营销办法#第十条 | 内容禁止：虚假误导、保本承诺、夸大、"低风险/低门槛/秒到账/高收益/低利率/无成本"等诱导词 | 一切营销文案 |
| 网络营销办法#第十一条 | 多类金融产品（存款/理财/保险/支付/信用卡等）须**分别设宣传展示专区** | 聚合页混合展示多类产品 |
| 网络营销办法#第十三条 | 营销须提供拒收/退订，**退订后不得同方式再发**；算法推荐须提供非个性化选项或便捷关闭入口；不得诱导过度消费 | 短信/Push/精准推送 |
| 网络营销办法#第十五条 | 组合销售须显著提醒，**不得默认同意**，不得违法搭售 | 绑卡/加企微换权益/组合权益 |
| 网络营销办法#第十六条 | 公众号/直播/短视频营销须从业人员、获授权、内容审核、可回溯 | 直播/短视频/KOL/企微 |
| 网络营销办法#第十八~十九条 | 账号名称/商标使用涉金融字样须与资质一致 | 自营账号/联名 |
| 网络营销办法#第二十~二十四条 | **第三方平台合作**：事前评估、书面协议、责任划分（本行不因委托免责）、品牌独立清晰展示产品提供者 | 与第三方平台联合营销/绑卡 |
| 网络营销办法#第二十七条 | 第三方需客户信息须授权、保障数据安全、**不得擅自跨平台传递** | 第三方涉客户信息 |

## B. 消保办法（所有涉客产品 / 服务 / 营销 场景，默认适用）

| 条款 | 要点 | 触发场景 |
|------|------|---------|
| 消保办法#第九条 | 设计/定价/协议/营销环节须经消保审查 | 前置消保核验 |
| 消保办法#第二十三条 | 不得欺诈/隐瞒/误导，不得夸大收益或权益、掩饰风险 | 利益点/收益类文案 |
| 消保办法#第二十六条 | 保障自主选择权，不得默认/强制捆绑 | 勾选项/搭售 |
| 消保办法#第二十八条 | 保障公平交易权，不得对同等条件消费者不公平定价/差别对待 | 差异化客群/定价 |
| 消保办法#第四十条 | 营销须提供拒收/退订，**退订后不得同方式再发** | 短信/群发/推送 |
| 消保办法#第四十四条 | 线上格式条款获取个信授权**不得默认勾选** | 授权弹窗/加企微 |
| 消保办法#第四十五条 | 与合作方处理个信须协议约定数据保护/保密/违约/终止处置 | 第三方合作 |
| 消保办法#第四十六条 | 未经消费者同意不得跨平台传递个信 | 第三方/跨平台 |

## C. 广告法（涉自制宣传物料 场景）

| 条款 | 要点 | 触发场景 |
|------|------|---------|
| 广告法#第九条(三) | 禁用"国家级/最高级/最佳"等绝对化极限词 | 物料文案 |
| 广告法#第九条(一)(二) | 不得损害国家尊严、不得用国旗/国徽/国歌、机关名义 | 物料视觉/文案 |
| 广告法#第九条(九) | 不得含性别歧视内容 | 涉性别物料 |
