# ⑤ 评估准确性 · 规则库

> 来源：声誉风险分级模型（完整版见 `assessment-manual/声誉风险分级模型.md`）。
> 本维度与事件库联动强：调取历史舆情场景，佐证或质疑处室自评。

---

## 1. 分级速查表

从**事件性质、舆论背景、涉及范围、总体影响**四个维度综合判定，取孰高原则。

### 一级（极高）— 总行办公室必须报备

**总体影响：** 引发社会广泛关注，可能导致重大损失、系统性风险或严重负面影响。

**触发信号（任一即可）：**

- 全行或多省市电子渠道/网点中断 ≥ 3小时；或因网络欺诈/信息安全事件造成重大社会影响
- 涉及盗窃、出卖、泄露本行商业秘密的事件，可能影响经营稳定导致经营秩序混乱
- 网点挤兑事件
- 因突发公共事件（自然灾难/事故灾难/公共卫生事件/社会安全事件）导致较多人员伤亡的各类事故
- 监管罚款 ≥ 1亿元
- 高级管理层被采取强制措施/失联/非正常死亡
- 因员工不当言行，引发重大社会舆论事件
- 可能引发系统性金融风险
- 涉及重大政治敏感事件（两会/国庆/台湾/新疆等敏感时点+负面内容叠加）
- 因产品/系统缺陷导致客户大范围资金损失（如原油宝事件类）
- 涉众面广，易引发群体性事件
- 涉及公众人物、弱势群体、特殊职业人群、敏感特殊人群等**双重或多重身份**人员（区别于二级：二级是单一身份即触发，一级须双重/多重身份叠加）

### 二级（高）— 总行办公室须报备

**总体影响：** 较大负面影响，影响持续扩大，本行在舆论中处于不利地位。

**触发信号（任一即可）：**

- 由银行经营管理中存在的较大风险漏洞、违规操作等而引发舆情，事件关系到客户的切身利益、性质较为恶劣
- 省/市级电子渠道/网点中断 30分钟至3小时
- 聚众上访、围堵或冲击本行办公及营业场所，致1个网点停业30分钟至4小时以下，或造成社会影响
- 监管罚款 800万元（含）至1亿元以下；或多机构同批 ≥5000万元
- 一级分行、子公司主要负责人不明原因外逃/出走/失踪/非正常死亡，或因违规违法被有权机关采取强制措施
- 对本行内部改革、资本补充、机构设置、人事薪酬等各类经营管理问题的负面报道及不实解读
- 针对本行经营业绩、业务发展、风险合规管理等歪曲事实或恶语攻击的不实/倾向性报道，造成本行财务损失、股价大幅下跌或客户流失
- 恶意集纳相关负面信息，炮制"标题党"，并恶意关联主要行领导
- 有其他银行近期发生类似事件，公众情绪已积累
- 事件亲历者为弱势群体（老弱病残孕/农民工）
- 事件传播者为特殊职业人群（记者/律师/网红）

### 三级（中）— 总行办公室须报备

**总体影响：** 有一定负面影响，但整体声誉损失可控。

**触发信号（任一即可）：**

- 监管罚款 50万元（含）至800万元以下
- 反映银行服务/产品的普通负面报道，尚未引起大面积关注
- 公司常规管理举措被媒体提及或偏向负面的报道
- 对本行业绩报告进行负面解读报道
- 涉及客户服务态度、收费标准等个案类投诉
- 传言类事件（无法证实或证伪）
- 银行干部员工（除一二级风险事件所述人员外）不明原因外逃/出走/失踪/非正常死亡，或因违规违法被有权机关采取强制措施
- 涉及具有一定刻板印象的群体（学生/环卫工人、贵宾客户及其子女等）

### 四级（低）— 部门内部标准流程

**总体影响：** 影响范围较小，可通过标准渠道快速处置。

**触发信号（全部满足才能定为四级）：**

- 监管罚款 < 50万元，或普通诉讼
- 客户普通抱怨，可快速沟通安抚
- 孤立偶发事件，无传播扩散迹象
- 媒体无意中提及本行负面事件，未有针对性和指向性
- 无特殊舆情背景，涉及范围为普通利益相关者

## 2. 定级常见偏差

### 偏低定级（处室倾向于低报，以简化审批流程）

| 高风险场景                           | 处室常见低报 | 正确判断                         |
| ------------------------------------ | ------------ | -------------------------------- |
| 3·15前后的营销活动                  | 四级         | 至少三级，敏感时点本身是加权因素 |
| 涉及老年客户的复杂产品推介           | 四级         | 三级（弱势群体）                 |
| 活动出现系统故障导致少量客户无法参与 | 四级         | 视影响范围，可能三级             |
| 企微大规模推送但话术未经审核         | 三级         | 可能二级（言论失控风险）         |
| 近期同类银行发生舆情，本行同类活动   | 三级/四级    | 至少三级，需同步关注同业舆情     |

### 偏高定级（罕见，通常出于谨慎，无需纠正，但可核实）

| 场景                                                                                                              | 误判定级               | 正确判断                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 命中事件库/历史案例同类风险点，但案例本身未达二级量化门槛（无具体罚款金额、业务中断时长、弱势群体涉及等触发信号） | 二级                   | 命中案例只能证明该类风险真实存在、并非臆测，不单独构成提级依据；仍须回到第1节分级速查表核验事件性质/舆论背景/涉及范围/总体影响，通常为三级                                                                                      |
| 同类问题在系列活动（如24节气）中重复出现、上一期评审已明确指出仍未整改                                            | 因"重复未整改"直接提级 | 重复未整改反映的是**处室整改执行力/评估准确性**问题，应在本维度结论中作为评估扣分项说明，不能单独拉高声誉风险等级——除非未整改已导致事件性质本身升级（如从"潜在风险点"变为已发生的实际客户投诉、监管约谈等具体触发信号） |
| **送审材料缺失**（声誉风险事前评估表/消保审核记录/广告宣传规范审核表等未提供）                                    | 因"材料不全"拉高定级    | 活动评审是正式上线前的**前置环节**，后续还有声誉风险评估、消保、各级审批流程，材料会在这些环节补齐。材料缺失只影响**总体结论**（评审范围受限、不出无保留"建议通过"）并列为**提示项**（备注注明须补齐），**不驱动风险等级**。因缺料无法判断是否存在更高风险时，在备注**暴露不确定性**（Fail Loud），不臆测提级 |
| **物料/页面占位符、原型稿未定稿**（占位文案如"活动名称"、假数据、模板水印、联系方式/供应商占位符、月份轴等与实际不符的样板值） | 因"占位/未定稿"拉高定级 | 前置评审阶段占位符默认视为**未定稿**，只作**提示项**（列明"正式发布前须填入/替换并与规则核对一致"），**不驱动风险等级**。仅当占位内容本身反映**活动设计缺陷**（而非单纯没填）时才计入内容风险。占位导致的"跨材料不一致"同理——本质是未定稿，归提示 |

> **典型纠错案例**：2026-06-22 小暑节气活动评审，曾因"中奖概率未公示、浏览任务监管关注风险均与夏至活动评审（2026-06-09）同款且未整改"，将定级由三级误判为二级；复核后确认两项问题均未达二级量化门槛（无具体罚款/业务中断/弱势群体等触发信号），且舆情扫描无相关苗头，应为三级。已纠正，详见 `work/活动评审/20260623-2026年小暑节气活动/output/评审结论.md`。

> **典型纠错案例（材料缺失/占位符不提级）**：2026-07-15 支付有礼、立秋活动评审，初判均为三级，其中"支付有礼"三级依赖了"缺评估表/消保记录 + 活动页面占位稿 + 页面奖池与规则不一致（占位所致）"；安之指出材料缺失与占位符是前置环节的正常状态、只提示不提级。剔除后严格逐维套第1节四维模型：**支付有礼**四维无一锚定三级 → 改判**四级**；**立秋**因"浏览/关注理财产品换抽奖"恰逢工信部2026-06-10 App跳转监管新规、命中**舆论背景维**"与当下热点关联/可能延伸损害银行形象" → 取孰高**维持三级，但定级依据由"材料/叠加"更正为舆论背景维**。教训：先例参照与速记表不能替代逐维取孰高；材料缺失/占位符不得进入定级驱动项。此为安之 2026-07-15 明确要求固化。

## 3. 评估准确性核验步骤

> ### ⛔ 定级铁律（火眼金睛 / 照妖镜共用，逐条执行不可省）
>
> 1. **必须逐维套模型、取孰高**：任何定级，一律回到第 1 节四维度（事件性质 / 舆论背景 / 涉及范围 / 总体影响）**逐维**判定，再按**孰高原则**取最高维的等级。**禁止**用"先例参照""速记表""感觉差不多""叠加了好几个问题"代替逐维判定——先例与速记表只是提要与佐证，不是定级依据。
> 2. **写定级依据必须点명是哪一维触发**：结论里的"定级依据"要写清是四维中的**哪一维、命中该维的哪条标准**（如"舆论背景维——理财导流恰逢工信部App跳转监管新规，与当下热点关联"），不能只写"综合判断为X级"。
> 3. **不得进入定级驱动项的因素**（只提示、不提级，详见第 2 节"偏高定级"表）：①送审材料缺失（评估表/消保/广告审核表等，前置环节会补齐）；②物料/页面占位符、原型稿未定稿（含占位所致的跨材料不一致）；③事件库/历史案例命中、系列活动重复未整改。这些一律写入"问题清单/备注"**提醒到位**（正式发布前须补齐/整改），但**不抬高风险等级**。
> 4. **暴露不确定性**：因材料缺失无法判断是否存在更高风险时，在备注 Fail Loud，不臆测提级、也不臆测降级。

**Step A：看总体影响描述是否准确**

- 处室的风险描述是否有具体风险点
- 还是仅写"可控"、"低风险"等空话（→③材料规范性也会标注）

**Step B：检查四维度是否完整分析**

- 事件性质：是否识别了本次事项的主要风险类型
- 舆论背景：是否考虑了时间节点、行业热点
- 涉及范围：是否考虑了受影响人群的特殊性
- 总体影响：是否基于以上三点给出合理判断

**Step C：与事件库历史舆情比对**

- 调取同场景的预警清单
- 检查处室评估中是否遗漏了历史上曾出现的同类风险

**Step D：等级核验**

- 对照第1节分级速查表，判断处室自评是否合理
- 若有明显偏差（≥2级），在Phase 3给出提级建议
- ⚠️ 事件库/历史案例命中、同类问题重复未整改，均只用于佐证风险真实存在或反映评估执行问题，不单独构成提级理由——常见误判及纠错案例见第2节"偏高定级"

```
⑤ 评估准确性：
  风险描述质量：[充分 / ⚠️ 描述笼统，具体风险点为：XXX]
  四维度覆盖：[完整 / ⚠️ 缺少：舆论背景/涉及范围分析]
  事件库历史比对：[无遗漏 / ⚠️ 发现处室未提及的历史风险点：XXX]
  处室自评等级：[X级，判断合理 / ⚠️ 低估：根据XXX，应为X级]
  本维度结论：[通过 / ⚠️ 评估不充分（需补充：XXX）]
```
