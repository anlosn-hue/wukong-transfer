## 1. 标准审批链路

### 部门内部链路（由下至上）

```
拟稿人（处室）
    ↓
处室声誉风险管理员（核心节点，必须出现）
    ↓
处室负责人（必须出现）
    ↓
处室分管领导（必须出现，见豁免规则↓）
    ↓
【本节点】部门舆情管理员（悟空所在环节）
    ↓
综合处主要负责人
    ↓
部门主要负责人
    ↓
（三级及以上风险）→ 总行办公室
```

> **豁免规则：处室分管领导 = 部门主要负责人时，处室分管领导节点可豁免。**
> 当某处室的"处室分管领导"同时担任"部门主要负责人"（示例见 `private/处室清单.md`），其签批已涵盖在链路末端"部门主要负责人"节点，因此处室这段可直接从处室负责人提交至部门舆情管理员，无需在"处室分管领导"环节额外重复签批。
> 核验方法：查 `处室清单.md` 该处室"分管领导"一列；再查"部门级审批人"表中"部门主要负责人"一列；姓名一致即触发豁免。

### 消保审查链路（须先于声誉风险评估完成）

```
拟稿人 → 处室负责人 → 消保审核员 → 发起人（消保流程记录存档）
```

**消保先行原则：** 消保审查的完成日期必须早于声誉风险评估表的提交日期。若申请材料显示两者同日或消保在后，标注 ⚠️。

## 2. 审批单比对协议

**前提：** 处室提交了日常事务审批单（纸质扫描图片或已填写的电子版）。

### Step A：提取审批链信息

从审批单中提取以下信息，记录到比对表：

| 字段 | 提取值 |
|------|--------|
| 拟稿人姓名 | |
| 拟稿部门 | |
| 拟稿日期 | |
| 各审批节点姓名（按顺序） | |
| 各审批节点日期（按顺序） | |
| 汇签意见摘要（若有） | |

### Step B：加载处室清单

读取 `knowledge/tools/assessment-manual/private/处室清单.md`，找到对应处室的人员信息：
- 处室声誉风险管理员姓名
- 处室负责人姓名
- 处室分管领导姓名

### Step C：逐项比对

| 检查项 | 预期 | 实际 | 结论 |
|--------|------|------|------|
| 处室声誉风险管理员是否出现 | [处室清单中的姓名] | [审批单提取值] | 匹配/❌不匹配/⚠️未填 |
| 处室负责人是否出现 | [处室清单中的姓名] | [审批单提取值] | 匹配/❌不匹配/⚠️未填 |
| 处室分管领导是否出现 | [处室清单中的姓名] | [审批单提取值] | 匹配/❌不匹配/⚠️未填 |
| 审批顺序是否正确 | 管理员→负责人→分管领导 | [实际顺序] | 正确/❌倒序 |
| 日期是否顺序递增 | 各节点日期单调递增 | [实际日期序列] | 正常/⚠️日期异常 |

### Step D：特殊报备核验

核查是否需要外部报备：
- **风险等级三级及以上** → 须报总行办公室；**三级须提前3个工作日**提交（含日审正文+附件），核验拟稿日期与维护/活动日期之间的工作日数是否满足
- 风险等级一二级 → 同上要求，且通常须更早报备，核查日审是否附带已报备记录
- 分行机构发起的事项 → 是否已按审批流程清单完成分行端的报备

## 3. 无审批单时的处理

若处室未提交审批单，或仅提交日审正文而未附流程单：

1. 在③材料规范性中标注"审批流程单缺失"
2. ②流程合规性基于申请材料中的自述信息进行有限核验
3. 若申请材料中未提及消保审查结论，标注 ⚠️

## 4. 常见流程合规问题

| 问题类型 | 表现 | 建议处理 |
|---------|------|---------|
| 跳级审批 | 处室负责人之后直接到部门 | 退回补充处室分管领导审批 |
| 消保滞后 | 消保完成日期 ≥ 声誉风险评估日期 | ⚠️ 提醒确认顺序 |
| 审批人身份存疑 | 姓名与处室清单不符 | ⚠️ 建议核查，不强制判死 |
| 代审批 | 审批意见格式异常，疑似代签 | ⚠️ 提醒确认 |
| 外部报备遗漏 | 三级/二级风险但无总行报备记录，或报备距维护日不足3个工作日 | 要求补充或确认时间节点 |
