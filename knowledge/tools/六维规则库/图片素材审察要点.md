# 图片素材审察要点

> 跨维度辅助文件（与「法规要点速查.md」同级，不编号）。火眼金睛 / 照妖镜共用。
> 触发：材料清点发现图片文件时逐张加载审察。
> 设计依据：docs/superpowers/specs/2026-07-08-图片审察与网评建议-design.md

---

## 0. 审察协议（硬性）

1. 材料清点列出全部图片文件（png/jpg/jpeg/gif/bmp/webp/heic 等一律计入），逐张用 Read 打开审察
2. **读取失败不得静默**：遇不支持格式、损坏文件或读取报错 → 清单标注「无法读取，需人工看图」并计入报告待确认项
3. 每张图先做 ① 画面文字逐字转录，再过 ② 图文一致性，随后按画面内容触发 ③–⑦
4. 发现来源统一标注 `[图片:文件名]`
5. 报告注明：含图片 N 张，已审察 X 张，无法读取 Y 张

---

## 1. 画面文字合规（每张必查）

先逐字转录画面全部文字（含小字、角标、水印），再按以下检查：

- 绝对化/夸大词语：必得、100%、最高、第一、免费、稳赚、保本、无风险
- 风险提示：理财/投资类须有"理财非存款，产品有风险，投资须谨慎"等提示字样，且**字号可读**——提示字过小本身即投诉点
- 收益表述：利率/收益率是否标注口径（年化/业绩比较基准），有无只标大数字不标条件
- 禁用表述："本活动最终解释权归…所有"（消保明令禁止）
- 小字陷阱：限首次/限白名单/限量/限时段等关键限制条件是否用极小字号隐藏——易被打成"套路营销"
- 低级错误：错别字、病句、单位错误（%/‰、万/亿）——上网即被嘲讽，亦是形象风险

## 2. 图文一致性（每张必查）

对方案/话术/评估表逐字段钩稽（接入现有跨材料一致性核验）：

- 活动时间、力度金额、参与对象、奖品名称与数量、产品名称、利率/费率数字
- 海报口径比方案宽 → 虚假宣传风险；比方案窄 → 公平交易权投诉。两方向风险不同，一律退回明确口径

## 3. 画面元素政治/社会敏感性（按画面触发）

- 地图：国界完整性、是否经品牌/办公室审核
- 国旗、国徽、军装、人民币图样、领导人形象、天安门等元素使用规范
- 人物形象：性别刻板印象（妇女权益法）、儿童形象（肖像授权/诱导未成年）、宗教/民族服饰符号误用
- 文化禁忌与时政撞车：谐音擦边、不吉利联想、画面场景与近期负面热点巧合

## 4. 授权与知识产权（按画面触发；均为"需确认授权"提醒级，只标疑点）

- 字体（商用授权重灾区）、图库素材来源、外部 IP 形象授权、名人/素人肖像权
- 本行 IP（兴福龙）名称与形象使用是否正确

## 5. 必备要素完整性（按画面触发）

- 发起主体全称/落款是否齐全
- 营销内容是否按《金融产品网络营销管理办法》要求可识别为营销信息
- 活动细则入口（详见细则/二维码）是否存在

## 6. 传播风险·被截图恶搞视角（按画面触发）

- 构图/文案组合被裁切、断章取义后是否变味
- 谐音双关有无恶意解读空间
- 二维码/短链指向需确认（是否与物料承诺页面一致），标注"需确认指向页面"

## 7. 明显品牌错误（按画面触发；仅错误级，VI 细审留照妖镜 Phase 4 预留接口）

- 行名错字、logo 明显变形/旧版、与合作方 logo 并列位次不当

---

## 8. 维度映射（发现归入现有维度，不设独立 Phase）

| 审查组 | 火眼金睛归入维度 | 照妖镜归入 |
|--------|----------------|-----------|
| 1 画面文字合规 | ③ 材料规范性（另触发法规速查 C 广告法） | Phase 1 宣传物料·广告法合规 |
| 2 图文一致性 | ③ 材料规范性（跨材料一致性核验） | Phase 1 跨材料一致性 |
| 3 画面元素敏感性 | ① 政治敏感性 | Phase 2 政治敏感性维度 |
| 4 授权与知识产权 | ③ 材料规范性（提醒级） | Phase 1 宣传物料·版权合规 |
| 5 必备要素完整性 | ③ 材料规范性 | Phase 1 宣传物料 |
| 6 传播风险 | ④ 事项合理性 | Phase 1 触客话术·客诉敏感点同类 |
| 7 明显品牌错误 | ③ 材料规范性（提醒级） | Phase 1 宣传物料 |

## 判断结论格式

```
图片素材审察：
  图片清点：共N张，已审察X张，无法读取Y张（[无法读取的文件名列表]）
  1 画面文字：[无问题 / ⚠️ [图片:xxx.png] 发现：…]
  2 图文一致性：[一致 / ❌ [图片:xxx.png] 与方案不一致：…]
  3–7 触发项：[未触发 / ⚠️ [图片:xxx.png] …]
```
