# ① 政治敏感性 · 规则库

> 来源：声誉风险分级模型（一/二级舆论背景 + 事件性质）、行内管理实践。
> 本维度事件库联动较弱，主要依赖本文件。

---

## 0. 价值根基：金融的政治性与人民性（本维度内核·最高研判维度）

> 来源：2023年10月中央金融工作会议；2024年1月习近平省部级专题研讨班讲话（"中国特色金融发展之路"八个坚持）；金融监管总局关于"把握金融工作政治性、人民性"的要求。
> 这是声誉风险的**最高维**：比合规更根本。合规问"违不违规"，政治性/人民性问"方向对不对、立场站哪边"。**很多重大声誉事件不违反任何具体合规条款，却因背离这一层而引爆**——只能靠价值层的语义判断识别，是 LLM 研判的重点。

**政治性** = 金融必须讲政治、守方向：服务实体经济与国家大局，不脱实向虚；维护国家金融安全；不触碰共同富裕、社会公平这条政治红线；不异化为固化阶层、输送特权的工具。

**人民性** = 金融为人民、成果由人民共享：发展普惠金融惠及最广大群众；不"嫌贫爱富"、不搞特权服务、不利益输送损害公平；金融做得好不好，最终看老百姓的获得感与公平感。

### 高危信号（命中即属本维度重大风险，通常提级至一/二级，即便无具体合规违规）

| 信号 | 典型表现 |
|------|---------|
| 利益输送 / 特权服务 | 向特定客户（私行/高净值）输送稀缺社会资源或特权待遇：名企实习、稀缺名额、超常规便利、子女升学就业便利 |
| 嫌贫爱富 / 显失公平 | 按财富或身份差别对待，普通客户无缘；放大而非弥合阶层差距 |
| 有违共同富裕 | 业务/活动设计固化阶层、加剧不公，与共同富裕政治任务相悖 |
| 脱实向虚 / 金融异化 | 金融背离服务实体经济本分，沦为资源寻租、空转套利的中介 |
| 损害党和国家形象 / 政治方向 | 立场、表态与党的方针明显相悖 |
| 易引爆公平类社会情绪 | 触发"阶层固化""寒门难出贵子""特权""不公"等社会情绪，舆论一点就着 |

### 典型案例：私行客户子女"大厂实习"特权

某行向私人银行客户子女提供互联网大厂实习机会，**未违反任何传统合规**（无误导宣传、无投诉、无违规营销），却构成重大声誉风险：
- **违人民性**：把本应公平竞争的稀缺社会资源（名企实习）当作金融服务的特权附加权益，定向输送给富裕客户子女——"嫌贫爱富"，金融成了放大阶层不公的工具。
- **违政治性**：①金融异化为"资源寻租中介"（拿对公关系换实习名额，本质是权力/资源交易）；②直接触碰共同富裕政治红线；③必然引爆"寒门难出贵子""阶层固化"社会情绪，构成政治风险。
- **研判要义**：风险**不在业务层、在价值层**。关键词与消保红线都抓不到，必须靠对"政治性/人民性"的语义判断。

### 研判规则

- 任何事项/舆情，**先过这一层，再看合规**。
- 命中高危信号 → 直接判定本维度重大风险，并在结论中明确"违背金融的政治性/人民性"。等级：
  - **涉利益输送 / 特权服务 / 显失公平**（如私行客户子女名企实习特权）→ **定一级（最高风险）**。性质恶劣、不可逆、舆论必然引爆，按真实案例口径顶格。
  - 其余政治性/人民性信号 → 通常一/二级，视发酵程度定。
- 即便活动方无主观恶意，只要客观上形成特权/不公观感，即应预警。

以下时点期间执行的事项，即便四级风险也应专项注明（部分可能需提级或上报）：

| 时点 | 敏感程度 | 说明 |
|------|---------|------|
| 3·15消费者权益日（前后各1周） | ★★★ 极高 | 媒体主动挖掘，任何客户服务瑕疵均可能被放大 |

| 全国党代会 | ★★★ 极高 | 同两会 |
| "七一"建党纪念日（前后1周） | ★★ 高 | 政治宣传密集期，商业宣传需与政治主旋律协调 |

### 不定期敏感时点
- 本行年报/半年报发布前静默期
- 本行发债、增发股票过发审会前
- 本行高管更换前后
- 行业内发生类似声誉事件、公众情绪积累时
- 全国哀悼日或重大突发公共事件期间（不可开展促销类活动）

### 1.1 活动执行期"跨"敏感时点的处置判据（2026-07-23 新增）

上表按"时点"设计，但营销活动多为**跨周期执行**（节气/节日活动常 2 周以上），实际遇到的往往不是"活动落在敏感日当天"，而是**活动期把敏感时点包在中间**。此时不应简单二选一（整体提级 or 视而不见），按下列判据处置：

| 判定 | 处置 |
|------|------|
| 活动期与 ★★★ 极高时点（3·15、两会、党代会）重叠 | 基础定级强制托底三级；建议整体错峰或暂缓 |
| 活动期与 ★★ 高时点（9·3、9·18、七七、七一、十一）重叠 | **不必整体停办，但敏感日前后 ±2 天暂停促销类内容的主动推送**（短信/Push/朋友圈/企微群发），活动页保持可访问但不做新增曝光；在评审意见"备注"中专项注明并写清建议暂停的具体日期区间 |
| 活动期与本行静默期（年报/半年报/发债）可能重叠 | 悟空无法自行判断，一律在备注要求处室核实披露日期；若重叠则大规模投放错峰或报办公室知悉 |

**要点：** ①判断对象是"**主动推送动作**"而非"活动是否存在"——纪念日的忌讳在于商业促销的**曝光行为**打扰庄重氛围，不在于客户自己点进活动页；②建议须落到**具体日期区间**（如"9 月 1 日至 9 月 5 日暂停"），只写"注意避让"处室无法执行；③逢十周年等更高规格纪念安排（有阅兵、公祭等）从严掌握，必要时整体错峰。

**关联案例：** 2026 年处暑活动评审（20270723-处暑活动，活动期 8/23–9/6 完整覆盖 9·3 及前后 3 天）——本条判据即由该次评审提炼。

**1.1.1 固定月度节奏活动的结构性撞期（2026-07-27 新增）**

上述"跨敏感时点"判据针对**单次评审**发现的时间窗重叠；但部分活动按**固定日期节奏**长期滚动（如每月固定 18 日、每月固定某周等），其撞期不是一次性偶然，而是**逐年必然重现**——每次评审若只核对本次申报周期，会年复一年地漏判同一个撞期。

**检查方法：** 遇到"每月固定 X 日启动/开展"类活动，除核对本次申报周期外，额外核对 X 日在**日历全年**中是否命中 §1 固定敏感时点表（尤其 9·3、9·18、七七、七一、十一等 ★★ 高时点，其"当日"属性使固定日期活动结构性命中概率显著高于偶然重叠）。命中的月份按 §1.1 判据处置（±2 天暂停主动推送），并在意见中注明"该月份逐年重现，建议纳入活动固定执行清单长期遵循"，避免下一年度经办人换人后重新踩坑。

**关联案例：** 2026-07-27"兴运理财日"活动评审（工作目录 `work/声誉风险评估/20260727-兴运理财日活动/`）——该活动按"每月 18 日至月底"固定节奏开展（2026 年 8-12 月共 5 期），其中 9 月期（9/18-9/30）启动日恰为"九一八"事变纪念日当天，且期末临近"十一"避让窗口；本条判据即由该次评审提炼。

## 2. 政治禁区（一票否决项）

以下任一情况出现，直接判定存在政治敏感性风险，需专项说明或退回修改：

- **国家象征**：涉及国旗、国徽、国歌的不当使用或变形
- **领土主权**：涉及台湾、香港、澳门主权表述有误；涉及新疆、西藏敏感地域表述
- **党政禁区**：贬损党和国家领导层；与党的政策方向明显相悖的立场表达
- **意识形态**：宣扬封建迷信、历史虚无主义；涉及境外敌对势力的表述
- **敏感词汇**：使用未经明确授权与银行业务关联的政治性词汇（如"共同富裕"需有实质内容支撑，不可空喊）
- **网络政治隐喻符号**：活动设计、宣传图、话术中是否出现已被赋予政治含义的网络符号。常见高危符号（不限于此）：白纸/A4纸、坦克图案、特定日期数字组合（如"6/4"）、"蛋炒饭"等网络梗、坦克人相关意象。即便创作者无意为之，也可能被截图断章取义引发舆情。→ 发现即标注，建议删除或替换（非一票否决）

## 3. 言论风险

适用场景：涉及员工企业微信、外包人员、网红/KOL合作推广等内容执行环节。

**检查要点：**
- 是否对员工/外包执行人员的言论有明确约束条款（如话术模板、禁忌词清单）
- 企微朋友圈/群组发送内容是否经过审核，还是由员工自行发挥
- KOL/达人合作内容是否经过内容审核，能否把控传播边界
- 大规模外呼话术是否经过录音/质检抽查机制

**高风险信号：** 话术包含"保本"、"稳赚"、"国家背书"等不当表述；员工被要求自行分享、无审核机制。

## 4. 导向风险

宣传内容是否与监管导向相悖：

- 过度强调"高收益"，未充分揭示风险（与"卖者有责/买者自负"原则相悖）
- 宣传语暗示"国家保障"、"政府背书"（金融产品禁止此类表述）
- 针对老年客户推介高风险或复杂产品，与"适当性管理"要求相悖
- 营销内容以诱导性方式促使客户放弃冷静期或投诉权利
- **蹭社会情绪热点**：活动文案是否借用"躺平""内卷""打工人""贫富差距""失业""35岁危机"等负面社会情绪词汇做营销噱头。风险：易被解读为"消费公众焦虑"，引发反感；且此类话题本身敏感，监管关注度高。→ 发现即标注，建议替换为中性或正向表述（非一票否决）
- **违背"反内卷"政策导向**：业绩发布会、对外宣传、高管讲话中鼓吹加班文化（"白加黑""5+2""007""狼性奋斗"）、把员工超负荷当成绩炫耀，或宣扬以低价/高息恶性竞争抢市场（价格战、存款利率战、贷款利率内卷）。与中央经济工作会议"综合整治'内卷式'竞争"政策导向相悖。→ 发现即标注，建议删改
- **流露消极价值观**：对外表述、高管讲话渲染或认同"躺平""摆烂"等消极避世导向，与积极向上的主流价值导向相悖。→ 标注建议替换

## 5. 宣传表达失当（低级红 / 高级黑）

宣传"动机正确"不等于"表达安全"。表达方式失当本身就是政治敏感性风险：

- **低级红**：用力过猛、肉麻、形式主义的正能量宣传，本意歌颂却引发公众反感、群嘲。典型：把普通商业行为强行拔高为宏大叙事；苦情式宣传（吹员工带病坚守、暴雨中坚守、牺牲家庭"感动自己"）；过度煽情升华。→ 风险：被批"形式主义""作秀"，适得其反。发现即标注，建议改为平实克制表达。
- **高级黑**：表面正面、客观上抹黑或消解严肃性。典型：阴阳怪气、正话反说被解读为讽刺；把负面包装成正面反被识破；文案/设计客观上让本行或党和政府形象受损、解构主流价值。→ 风险：被指"动机不纯""暗讽"，政治性质恶劣。发现即标注、从严处理。
- **判断方法**：站在"最坏解读"视角——这段宣传被截图、被断章取义、被网友二创后，会不会变成对本行或主流价值的嘲讽/伤害？会则按低级红/高级黑预警。

## 6. 性别与女权议题（导向风险专项）

> 来源：男女平等基本国策；《广告法》第九条第（九）项（广告不得含性别歧视内容）；《妇女权益保障法》（2022修订，2023-01-01施行）第二十八条（禁止通过大众传播媒介或其他方式贬低损害妇女人格；媒体报道涉妇女事件应客观适度）、第四十二条（防止和纠正就业性别歧视），违反第二十八条的罚则见第八十二条；多地妇联推动的"广告性别平等审视"机制（如《深圳市广告性别平等审视指南》）。
> 性别议题是当前舆论场最易引爆、最两极化的领域之一：既要防"物化/歧视女性"被女性群体声讨，也要防"挑动性别对立/极端化"被反噬，还要防消解妇女节的政治严肃性。营销动机正面（赋能女性）但表达踩刻板印象同样翻车。

### 高危信号（命中即标注，多属导向风险；引发或可能引发热搜级声讨的提级）

| 信号类型 | 典型表现 |
|---------|---------|
| **物化女性** | 把女性简化为消费符号（"爱买买买""精致穷""女人就该对自己好"），诱导非理性消费/借贷；以身体、外貌做营销噱头或性暗示 |
| **性别刻板印象** | 强化"女主内/男主外""女性=妈妈/妻子/为家庭牺牲"的从属角色；贬低某一性别的能力与作用 |
| **容貌/身材/年龄焦虑** | 制造"白幼瘦""少女感""逆龄""冻龄"焦虑卖产品或医美贷；放大女性年龄焦虑 |
| **挑动性别对立** | 文案/话术制造男女对立、贬损或嘲讽某一性别博眼球（"普信男""扶弟魔""捞女"等对立标签）；选边站队蹭性别骂战流量 |
| **消解妇女节政治严肃性** | 以"女神节""女王节""三七女生节"替代"三八国际劳动妇女节"，把政治性节日娱乐化、媚俗化、消费化；借妇女节搞低俗博眼球 |
| **服务/信贷性别歧视** | 信贷审批、产品准入、招聘宣传对女性（尤其孕产期、女性创业者）差别对待；女性专属产品溢价或捆绑消费 |
| **婚恋生育议题踩雷** | 催婚催生、彩礼、生育相关营销触碰社会敏感神经，易与人口政策、女性权益话题缠绕引爆 |
| **代言人/KOL 性别争议** | 合作的代言人/KOL 卷入家暴、性别歧视言论、物化争议导致连带塌房 |

### 研判规则

- **先问"是否客观上贬损、物化、或对立"，再看创作动机。** 动机正面但表达踩刻板印象同样翻车——典型：珀莱雅妇女节强行植入男性视角被骂上热搜、删微博；可口可乐"爹妈下厨房"陷刻板印象争议。
- 命中物化/歧视/侮辱 → 触《广告法》第九条 + 《妇女权益保障法》，按导向风险从严，建议退回修改；可能引爆热搜级声讨的提级。
- 注意"双向风险"：既不可物化/贬低女性，也不可借性别对立、极端化表达蹭流量；安全立场是回到"男女平等基本国策"的克制、尊重、去刻板化表达。
