# wukong-transfer — 悟空可移交副本

本仓是「悟空」——商业银行数字运营部门声誉风险管理 AI 工作台——的**可移交副本**：

- **文本资产在仓**：技能、知识库工具轨、SOP、模板、规范文件全部随 git 交付
- **重资产走离线包**：工作档案（work/）、内宣材料、原始资料、模板原件、处室清单等由离线数据包（U盘/网盘）交付，按 `data-manifest.md` 落位
- **git 历史为全新初始化**，与源仓无关，不含任何历史提交内容

用途：既供行内开发参考，也可由你的 AI 助手直接接管使用——照 `BOOTSTRAP.md` 复建即可。

## 快速开始（三步）

1. **clone 本仓**到本地工作目录
2. **落位离线数据包**：从移交人处取得 `wukong-data-YYYYMMDD.zip`，按 `data-manifest.md` 解压核对
3. **复建**：让你的 AI 助手（Claude Code 或兼容 agent）通读 `BOOTSTRAP.md`，逐节执行环境前置、配置、逐技能冒烟与验收清单

## ⚠️ 重要约定

- **勿直接修改本仓由源仓生成的业务内容**（技能文件、CLAUDE.md、知识库工具轨等）——本仓由源仓导出脚本单向同步，下次同步会整体覆盖你的改动。问题与改进建议请反馈移交人，由源仓统一修改后同步过来。
- 本地运行时数据（`memory/`、`work/`、活动方案库新卡、`knowledge/log.md` 新条目等）是你自己的积累，不受同步影响，注意自行备份（数据落位目录不随 git 同步）。
- 本仓 git 历史为全新初始化（orphan），与源仓无共同祖先；`git log` 首条应为占位初始提交。
