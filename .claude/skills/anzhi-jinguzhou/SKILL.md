# 紧箍咒 · 企微聊天记录质检

> 设计依据：`docs/superpowers/specs/2026-07-17-企微聊天记录质检-紧箍咒-design.md`
> 规则库：`references/质检维度规则库.md`（每条命中必须引用条目及出处）
> 脚本：`scripts/parse_chats.py`（机械解析）
> 数据区：`work/事后质检/`（仓内数据目录，不进 git）
> 原则：悟空判定、用户拍板；拿不准的进「待人工确认」，不静默吞掉。

## Step 0 收料确认
1. 确认 `work/事后质检/原始/` 有待质检 xlsx；与用户确认批次名（默认 `YYYYMMDD-文件名主干`）
2. 建 `work/事后质检/报告/<批次>/`
3. 格式异常（读不到 Sheet1 / 空文件 / A 列非会话文本）→ 报错停止，报告用户，不猜

## Step 1 机械解析
```
python .claude/skills/anzhi-jinguzhou/scripts/parse_chats.py <xlsx绝对路径> <报告/批次目录绝对路径>
```
产出 `01-解析.txt`。核对 stdout JSON：**未解析片段数必须为 0**，非 0 先解决（报用户或修数据）再继续。
Excel 行号是全流程主键，报告和清单里引用的行号都指 Sheet1 行号。

## Step 2 角色识别（逐会话，语义判定）
读 `01-解析.txt`，逐会话判定谁是客户经理、谁是客户：
- **强信号**（命中即定）：发言中产品链接 URL 含 `refereeId=`（推荐人ID，必为员工侧发出）
- 辅助信号（叠加判断）：推销话术方向（介绍产品/发链接一方）、称呼方式（"姐/哥/老师/您"）、
  实名无括号格式 vs `昵称(备注名)` 格式、姓名带工号数字后缀（如"黄娱娱123802"）
- 引用块（`「XX：…」`或`这是一条引用/回复消息`）内出现的员工发言可用于识别经理身份
- 判定不了（如整段仅客户发言）→ 标「经理无法识别，待人工确认」，内容仍质检
- 测试样例的 B 列是人工标注，只用于事后核对，**判定时不得读取**（生产数据没有 B 列）
- 群发/重复归并：同一经理相同文案发不同客户（或整行重复）→ 同一问题归并计一次，记录全部涉及行号
- 一段会话出现 3 个及以上发言人（群聊/多员工在场）→ 逐人套用上述信号判定，员工可能不止一名，所有员工发言均为质检对象；无法分派的发言人标「角色待人工确认」

## Step 3 七维规则扫描
逐会话按 `references/质检维度规则库.md` 七个维度过一遍：
①不当承诺与误导销售 ②消保合规 ③飞单私单与利益冲突 ④服务规范与态度
⑤敏感信息泄露 ⑥政治敏感与舆情隐患 ⑦话术质量
- 判定双层：关键词初筛 + 语义确认（同义表述按语义记，标注"语义判定"）
- 每条命中记录：行号 | 经理 | 维度 | 严重度（高/中/低）| 原话引用 | 规则库条目及出处 | 话术改进建议 | 附加标注（按需：「联动提示」「已撤回」「语义判定」「待人工定级」）
- 严重度取向：触法规红线/一票否决项=高；行内红线/擦边暗示=中；话术质量瑕疵类=低；拿不准的标「待人工定级」，不擅自定
- 语音/图片占位符内容不判；客户问敏感问题（保本?收益?风险?）而经理用语音回复的 → 记入语音盲区清单（严格命中）
- 盲区扩展情形同样纳入、标「扩展纳入」并注明理由（2026-07-18 用户确认宽口径）：收益/保本争议沟通中经理多段语音往来；客户复述疑似出自语音的承诺（"你说的保本"类）；文字合规澄清后又补发语音待核
- 撤回消息内容仍质检（已发出即有风险），标「已撤回」

## Step 4 审计关注点专项抽取
按规则库「审计关注点」节公式 **A ∧ 非b ∧ c ∧ 非D** 逐会话判定（独立于 Step 3，即使维度①已命中也要单独跑公式）。
边界处理全部按规则库判定细则执行（边界命中/引用块命中/疑似存款/群发归并）。
命中 → 进 `02-审计关注点清单.md`，严重度一律高。

## Step 5 报告产出
写入 `work/事后质检/报告/<批次>/`：

**02-审计关注点清单.md**（一等产出，需报送时可转 xlsx）：
```
# 审计关注点清单 · <批次>
> 公式：销售理财/基金/信托/保险 ∧ 无存款字眼 ∧ 保证性表述 ∧ 全程无风险提示（Sheet2 规则 A+非b+c+非D）

| 聊天行号 | 客户经理 | 发现问题点 |
|---|---|---|
| <行号，群发归并列全部> | <经理名或"无法识别"> | <原文引用 c 命中语句>；<缺失说明，如"全程无风险提示">；<边界标注，如有> |

数字运营部声誉风险管理智能体·悟空
YYYY-MM-DD
```

**03-体检报告.md**：
```
# 企微聊天记录质检报告 · <批次>
一、总览：会话数/消息数/命中总数；按维度分布表；按经理分布表；高严重度条目摘要
二、审计关注点：条数 + 指向 02 清单
三、七维明细：逐条命中（行号|经理|维度|严重度|原话|规则出处|改进建议），按维度分组
四、语音盲区清单：待人工抽听（行号|经理|客户所问敏感问题|语音位置）
五、待人工确认项：经理无法识别的会话、疑似存款边界案例、待人工定级条目
六、沉淀建议：规则库未覆盖的新隐患类型、命中投诉预警点的联动提示
数字运营部声誉风险管理智能体·悟空
YYYY-MM-DD
```
报告默认内部使用、保留原文引用；如需对外报送，转出前按金箍棒脱敏铁律去除客户可识别信息（姓名、手机号、卡号等），客户经理实名保留（质检对象）。

**xlsx 版本**（默认随 md 一并生成）：
```
python .claude/skills/anzhi-jinguzhou/scripts/md2xlsx.py <报告/批次目录绝对路径>
```
在批次目录生成 02/03 同名 xlsx（02 单表；03 分五个 sheet：总览/七维明细带筛选/语音盲区/待人工确认/沉淀建议）。标题与落款从 md 提取；排版为整行合并标题落款、自适应行高。md 有任何更新（含 Step 7 复核回填）后须重跑本脚本保持两版一致。

**产出前过体例规范**：md 与 xlsx 定稿前，逐条过 `knowledge/tools/报告体例规范.md`（A 术语口径／B 元话语／C 措辞／D 版面／E 高频词）。本技能高频踩中项：
- **A1** 内部术语不进交付件：七维规则代号、Sheet2 公式记法（A+非b+c+非D）、Step/Phase 编号、技能名。公式可留在方法说明处，但正文结论不得用代号指代
- **B1/B4** 报告不解释自身做法；删「结论是」「判定逻辑是」「需要说明的是」等铺垫语
- **B2** 同一口径说明只出现一次
- **C5** 判断句必须能指回条数或会话行号，指不回就不写
- **D2** 「**标题：** 说明」式内联标题列表改连贯段落或表格；**D6** 禁模糊归因
- **E 类**高频词黑名单
- **不适用**：A2（行名保留，不改「兴业银行」）、A5（本技能「问题点」指质检发现的服务问题，与投诉诉点无关，不改）、D1（emoji 一律保留）

## Step 6 沉淀回填（用户确认后执行）
1. 新隐患类型（规则库七维均不覆盖的新形态）→ 提示用户，确认后沉淀 `knowledge/tools/声誉风险事件库/` 对应类别 + `knowledge/cases/`（YYYYMMDD-关键词.md，**并在 `cases/INDEX.md` 登记一行**——不登记则技能按 INDEX 加载时该案例不存在）+ `knowledge/log.md` 记一条（**插在文件顶部**，前言 `---` 之后；按日期降序，勿追加到末尾）
2. 命中投诉预警点的业务 → 报告第六节标注，提示用户是否需要顺风耳搜一轮舆情
3. 任务跨会话未完成 → 按 CLAUDE.md 规则写海马体（附下次必读文件清单）

## Step 7 复核回填（触发词「质检复核」，或用户直接给出复核结论时执行）
报告中的待人工项（第五节待人工确认、第四节语音盲区、「待人工定级」条目）由人工复核后，结论回填：
1. 逐条应用复核结论：
   - **撤销**：如疑似存款核实确为存款 → 删除 02 清单对应条目及 03 报告维度①同源条目，并在该位置留一行撤销记录（原条目摘要+撤销原因+日期）
   - **定级**：「待人工定级」条目按复核结论改为高/中/低
   - **抽听结果**：语音盲区条目补记结论；抽听发现违规的，按七维/审计规则补录正式条目
2. 同步更新 02/03 两份 md 及其 xlsx 版本，重算总览统计（命中数/分布表）
3. 报告头部标注复核状态：全部待人工项闭环后标 `> 复核状态：已人工复核 YYYY-MM-DD（初稿 YYYY-MM-DD）`；只复核了部分条目时标 `> 复核状态：部分复核 N/M 项 YYYY-MM-DD`，剩余项保持待人工标注；无此标注即初稿
4. 复核中确认的新隐患走 Step 6 沉淀；**口径类裁定**（如新的边界判定规则）固化进 `references/质检维度规则库.md` 对应节并注明裁定日期，后续批次直接沿用

## 边界速查表
| 情形 | 处理 |
|------|------|
| 整段仅客户发言，经理不可判 | 标「待人工确认」，仍质检内容 |
| 经理仅存在于引用块 | 解析引用格式识别；其发言可构成审计命中 |
| 群发同文案多行/整行重复 | 归并计一次，列全部行号 |
| 语音/图片占位符 | 内容不判；敏感问答走语音的进盲区清单 |
| 撤回消息 | 仍质检，标「已撤回」 |
| 疑似存款产品用保本话术 | 抓 + 标「疑似存款产品，需人工核实」 |
| xlsx 格式异常 | 报错停止，报告用户，不猜 |
| 多方会话（群聊/多员工） | 逐人判定角色，全部员工发言均质检；分派不了的标「角色待人工确认」 |
