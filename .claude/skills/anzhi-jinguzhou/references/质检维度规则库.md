## 维度① 不当承诺与误导销售
1. 承诺/暗示保本、保收益、预测未来业绩（保本保息/稳赚/兜底/肯定有收益）——网络营销办法#第十条；六维规则库/01-政治敏感性.md 高风险信号词
2. 诱导性用语：低风险/低门槛/秒到账/高收益/低利率/无成本/放心投/闭眼入——网络营销办法#第十条；声誉风险事件库/03-客户服务.md（违规营销）
3. 随意承诺业务办理结果、审批结果、费息减免等不确定事项——声誉风险事件库/03-客户服务.md（严禁客服私自承诺）
4. 绝对化/夸大用语：必得/100%/最高/第一/稳赚/无风险——广告法#第九条(三)；六维规则库/图片素材审察要点.md
5. 擦边暗示刚兑：以历史兑付暗示未来（"之前到期100%做到"）、"贴钱做收益"、以"波动极小/摊余成本"暗示等同保本——严重度中；出处同第1条
6. 把监管审批/牌照表述为收益保证——网络营销办法#第十条
7. 越权承诺特殊办理、额外权益——声誉风险事件库/04-内部管理与合作方.md
8. 以额外利益诱导购买：现金返还/回扣/抽奖/红包/实物/代金权益/其他金融产品份额等与购买特定金融产品直接挂钩，作为购买条件、奖励或主要诱因（**员工个人返现、私发红包严重度高**，其余触监管禁止性销售规则者为中）——消保办法#第二十六条(四)（不正当手段诱使购买）；合规预警标签规则.md §二标签9（理财销售不得以抽奖、回扣、馈赠实物、代金权益及金融产品方式销售；基金销售不得以抽奖、回扣、送实物、保险、基金份额方式销售；不得返还现金或有价证券、赠送实物吸收存款）
   > 排除：产品自身依法约定的利息/收益/保险责任/合同权益；与购买特定产品无直接挂钩的一般客户服务权益（2026-08-09 由 12 标签对账缺口补入，本批命中 7 行）
9. 饥饿营销：以夸张额度、截止时间、稀缺性、抢购氛围或后悔成本促使客户仓促决策（"只剩最后一个名额""今天必须买""再不转钱永远买不到"）——消保办法#第二十六条(四)；合规预警标签规则.md §二标签8
   > 排除：客观说明明确的募集截止时间、活动期限或剩余额度且语气平实未施压；一次正常提醒；客户主动询问后的客观回复。与第 2 条诱导性用语的分工：第 2 条管**用词**（低风险/高收益等词表），本条管**施压结构**（时间/名额稀缺+催促）（2026-08-09 补入，本批命中 2 行）

## 维度② 消保合规
1. 金融消费者八大权利逐项核验（财产安全/知情/自主选择/公平交易/依法求偿/受教育/受尊重/信息安全）——六维规则库/04-事项合理性.md 核验表
2. 只讲收益不讲风险、风险揭示缺失——消保办法#第二十三条
3. 向老年/低风险偏好客户推介复杂或高风险产品且无适当性提示——六维规则库/01（导向风险）
4. 限制投诉权利、"最终解释权归我行"类表述——六维规则库/04（依法求偿权）
5. 个人信息收集/使用未获单独同意——消保办法#第四十四条；个人信息保护法#第十四/十七条（个保法无本地全文，条号引自六维规则库/04 既有引用，核对原文需另查）
6. 投诉与诉求受理后拖延、推诿、超时无反馈——声誉风险事件库/03-客户服务.md
7. 会话涉及投诉预警点在册业务（限额/征信/赎回到账/活动权益等）——knowledge/tools/投诉预警点/当前预警点.md，命中标「联动提示」

## 维度③ 飞单私单与利益冲突
1. 引导添加个人微信、私下沟通业务——声誉风险事件库/03（严禁客服私加客户微信）、01-数字营销活动.md（严禁用个人微信对客，全员企微）
2. 推介非本行产品、引导资金转往外部账户/渠道——声誉风险事件库/04
3. 私下承诺特殊待遇、向特定客户输送稀缺资源——六维规则库/01（利益输送/特权服务）
4. 企微营销从业人员资质与内容可回溯要求——网络营销办法#第十六条
> 本维度国家法规颗粒度粗，以行内红线为主（spec §四）。

## 维度⑤ 敏感信息泄露
1. 向客户/第三方透露他人账户信息、余额、账单、住址、手机号——声誉风险事件库/03
2. 将内部系统数据、客户画像标签内容告知客户或外泄——声誉风险事件库/03（按《企微服销一体化手册》红线）
3. 泄露业务数据、活动/权益核心规则等内部资料（含内部让利口径外泄，如"贴钱做收益"）——声誉风险事件库/04
4. 非本人业务查询、身份核验缺失——声誉风险事件库/03
5. 未经同意跨平台传递客户个人信息——消保办法#第四十六条；网络营销办法#第二十七条

## 审计关注点（管理员 Sheet2 规则，独立于七维单独抽取）

公式：**A ∧ 非b ∧ c ∧ 非D** 四项同时满足 → 进专项清单，严重度一律高（误导销售铁证）。

| 项 | 定义 | 词表（原样收录自 Sheet2） |
|----|------|--------------------------|
| A | 会话中销售的产品是理财/基金/信托/保险 | 理财\|基金\|信托\|保险（产品类型按语义判定，不只看字面） |
| 非b | 会话中没有存款类字眼 | 存款\|大额存单\|福运金 等字眼均未出现 |
| c | 经理使用保证性表述 | 和存款一样\|同存款一样\|安全保本\|本金安全\|本金不会损失\|本金没问题\|不会亏\|亏不了本\|本金绝对安全\|一分不少\|到期本金全回\|本金有保障\|保利息\|保收益\|保证收益\|收益没问题\|收益有保障\|肯定有收益\|到期能拿收益兜底\|亏了算我的\|向您保证不会亏\|保本保息\|保本金\|绝对盈利\|全部浮盈 |
| 非D | 全程无任何风险提示 | 产品有风险\|非保本\|不是预期收益率\|不代表预期收益率\|不承诺收益\|不保本\|不能保证收益\|没有承诺收益 等类似含义的表述，一句都没有 |

判定细则（spec §五定稿）：
- c 与 D 均为双层判定：词表原词命中直接记；词表未列但同义（如"本金相对安全"≈本金安全、"理财不保"≈不保本）按语义判定，c 侧标「边界命中」
- c 必须出自**经理**之口；客户说"保本吧？"经理未附和不算 c
- 引用块内的经理既往发言算命中，标「命中语句位于引用块」（2026-07-18 管理员裁定）
- 字面无存款字眼但语义疑似存款产品（如"1天通知/预约支取"指向通知存款）→ 仍抓，标「疑似存款产品，需人工核实」
- 经理擦边暗示但未构成 c、或说过风险提示（D 成立）→ 不进本清单，视情节进维度①
- 群发同文案多行/整行重复 → 归并计一次，列全部行号
