## Phase 0：接收材料

**Step 0.1 — 识别输入方式**

检查用户是否已粘贴申请材料文本：
- 已粘贴 → 直接进入 Step 0.2
- 未粘贴 → 询问：

  > 请提供申请材料。可直接粘贴日审正文，或告诉我已放入哪个 input/ 目录。如果同时有日常事务审批单（图片或已提取的文字），也一并提供，用于②流程合规性比对。

**Step 0.1b — 材料清点（硬性，不可跳过）**

用户给出文件夹路径时：用 Glob 枚举该目录全部文件，输出材料清单（文件名+类型），图片文件单独列出张数并向用户回报，逐张尝试打开确认可读性。无法打开的图片如实标注在清单中，**不静默跳过**。图片的具体审察判断（按七组要点逐条比对）留待 Phase 1 加载规则文件后，在 Phase 2 联动说明中统一执行——本步骤只负责清点与可读性确认。仅粘贴文本、无文件夹路径时本步骤跳过。

**Step 0.2 — 提取关键信息**

从申请材料中提取以下字段，未填写的标注"未提供"：

| 字段 | 提取值 |
|------|--------|
| 事项名称 | |
| 发起处室 | |
| 场景类型（勾选项） | |
| 执行时间 | |
| 渠道 | |
| 目标客群 | |
| 处室自评等级 | |
| 已提交附件 | |
| 是否附日常事务审批单 | 有 / 无 |

以简洁格式向用户确认提取结果。缺少次要字段不阻断流程，但缺少事项名称/处室/场景类型时询问补充。

## Phase 3：等级核验（轻量）

**加载参考：** `05-评估准确性.md` 分级速查表 + **§3"⛔ 定级铁律"（必读）** + `分级模型.md`（如需详查）

### 🚨 定级方法（硬性协议，与照妖镜同源，不可用速记表/先例代替）

对处室自评是否合理提出判断时，**必须逐维套《声誉风险分级模型》四维度（事件性质/舆论背景/涉及范围/总体影响）、取孰高**；给出的提级/维持理由须**点名是哪一维、命中哪条标准**，禁止只写"综合判断为X级"。

**⛔ 以下因素只写进意见「提醒到位」，绝不抬高风险等级（详见 05 §2/§3）：**
1. **送审材料缺失**（评估表/消保记录/广告审核表等）——只影响能否"确认等级"（可要求补料）与结论措辞，**不作为提级理由**。
2. **物料/页面占位符、原型稿未定稿**（含占位所致的跨材料不一致）——只提示"正式发布前须填入/替换核对"，**不提级**；仅当占位反映活动设计缺陷才计内容风险。
3. **事件库命中、系列活动重复未整改**——只佐证风险真实/反映处室执行力，**不单独提级**。

**基准原则：维持处室自评等级。**

仅在以下情况提出异议：
1. **差距≥2级**（如处室自评四级，但逐维套模型后某一维明确锚定二级）→ `⚠️ 建议提级至X级`，说明是**哪一维命中哪条标准**（来源标注 [规则库:05] 或 [分级模型]）
2. **特殊时点**（3·15/两会/重大节日前后）→ 即便四级也可能需要专项上报，给出专项提示
3. **材料明显不完整**→ 不予确认等级、要求补充材料（这是"暂不确认"，**不等于提级**——不得因缺料而抬高等级）
