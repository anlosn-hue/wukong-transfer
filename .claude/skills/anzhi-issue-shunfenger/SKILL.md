## Phase 0：初始化

**Step 0.1 — 解析 args**

从调用方传入的 args 字符串中解析参数，格式：`模式=快扫;关键词=A,B,C;行业=银行`

- 按分号拆字段，按逗号拆关键词列表
- 模式：快扫 / 深查；缺省时询问用户
- 关键词：逗号分隔；缺省时询问用户
- **自动调用兜底（无交互环境）**：若由照妖镜等技能自动调用、无法询问用户，且关键词缺省，则停止并向调用方输出：「顺风耳：未收到关键词，请在 args 中传入 `关键词=xxx`」；不继续执行后续 Phase。
- 行业：默认"银行"

**Step 0.2 — 读取配置**

读取配置文件，提取 `DAILYHOT_API_BASE` 字段值。

若文件不存在或字段为空，立即停止并提示：
> 顺风耳配置文件缺失或 API 地址为空，请先填写：`knowledge/tools/assessment-manual/private/顺风耳配置.md`

## Phase 1：热榜扫描

按以下顺序逐平台执行 WebFetch，URL = `{DAILYHOT_API_BASE}/{路由}`：

| 平台 | 路由 |
|------|------|
| 微博 | /weibo |
| 抖音 | /douyin |
| 百度 | /baidu |
| 知乎 | /zhihu |
| 新浪新闻 | /sina-news |
| 头条 | /toutiao |
| 澎湃新闻 | /thepaper |
| 腾讯新闻 | /qq-news |
| 百度贴吧 | /tieba |

**调用方式：** 对每个平台执行 WebFetch，URL 为 `{DAILYHOT_API_BASE}/{路由}`

**WebFetch prompt（每个平台统一用）：**
返回热榜条目列表，每条给出：排名、标题、热度值（如有）。如返回错误，只说"请求失败"。

**容错：** 单个平台 5xx 或超时 → 跳过，继续下一个；所有平台均失败 → 输出「热榜数据暂不可用」，不中断流程。

**过滤逻辑（命中任一即保留该条目）：**
- 包含行业标签词：银行、理财、基金、保险、投诉、消保、监管
- 包含关键词列表中任意一个
- 包含通用风险词：霸王条款、套路、维权、被骗、客服、扣款、未到账

**升级标注：** 若某条目同时满足 ①包含关键词 + ②排名前10，在该条目行末追加 ⚠️，例如：
`· [微博 #3] 某银行扣款投诉 —— 热度 150万 ⚠️`
若有任何条目触发升级标注，在本 Phase 输出末再追加一行：
`⚠️ 发现潜在高关联热点，建议在综合研判时纳入参考。`

## Phase 2：案例猎取（仅深查模式执行）

取关键词列表第一个词（关键词[0]），自动生成以下 4 组查询并执行 WebSearch：

```
{关键词[0]} 银行 活动 投诉 黑猫
{关键词[0]} 银行 舆情 媒体报道
{关键词[0]} 银行 处罚 监管
{关键词[0]} 银行 微博 OR 小红书 避雷
```

每组取前 3 条结果；合并去重；筛选最相关的最多 5 个案例进入输出。

**可信度强约束（严格执行）：**
- 每个案例必须包含来自本次搜索结果的原始 URL
- 无 URL 的条目记入"搜索线索"附录，不进正式案例节
- 禁止凭记忆补充案例，所有内容来自本次搜索结果

## Phase 3：输出

**快扫模式输出格式：**

```
⚡ 热榜速览（截至 HH:MM）
· [平台 #排名] 词条标题 —— 热度 XX
（无命中时）当前热榜未发现与本次活动直接相关的舆情苗头。
[如有升级标注，在此追加 ⚠️ 提示]
```

**深查模式输出（Markdown 节，供照妖镜直接嵌入）：**

输出以下结构：

## 舆情热点匹配

### 热榜速览（截至 HH:MM）
· [平台 #排名] 词条标题 —— 热度 XX

（若 Phase 1 有条目触发升级标注，热榜速览末尾同样追加全局 ⚠️ 提示行）

### 近期同类风险案例

#### 案例1：[案例标题]
- **案例概述**：（2-3句，事件经过和主要影响）
- **风险映射**：（与当前活动的对应关系，指出具体条款或设计元素）
- **来源**：[媒体/平台名称](原始URL)

若案例搜索无结果，输出：

若热榜和案例均无结果，仍保留"舆情热点匹配"节并说明，不省略该节。

## Phase 4：文件导出（手动触发深查时执行）

**触发条件：** 用户手动调用（非照妖镜自动调用）+ 深查模式 + 用户要求导出（说"导出""保存""存文件"等）。

**目录与文件命名规则：**

```
目录：./work/舆情监测/YYYYMMDD-[关键词[0]]舆情监测报告\
文件：YYYYMMDD-[关键词[0]]舆情监测报告.md
```

- YYYYMMDD = 搜索当日日期
- [关键词[0]] = Phase 0 解析的第一个关键词（即关键词列表第一项）
